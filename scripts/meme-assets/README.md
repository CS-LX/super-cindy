# 奶蛙版 Cindy 素材

本分支从上游 `2ce93d3631b58d12706094244244741e988d9b7c` 开始，不包含此前的步数上限和 loop 补丁。

素材取自 fork 所有者提供的《捧腹大笑思想与奶龙学概论》第一版。`originals/` 是 PDF 内嵌 JPEG 的原始字节；页码、图片索引与 SHA-256 记录在 `SOURCES.json`。不收录完整 PDF 或本机数据。所有角色均使用这些原图，没有使用 AI 重绘结果，没有重画眼睛、五官或身体。衍生处理仅为等比缩放、留白排版、图标圆角和格式转换。

覆盖桌面与移动端默认头像、16 格头像库、10 个内置伙伴包头像、应用与安装器图标、登录与启动插画、状态表情、分享图片、字标、灵动岛皮肤和 Cindy 角色壁纸。第三方供应商标志、普通功能图标和无角色的风景壁纸保持原样。已有账号、应用标识、设置键和壁纸 ID 保持不变；用户自己上传的头像和背景不会被覆盖。

角色壁纸随包加载，不再请求官方 CDN 的旧角色图片。灵动岛只移动整张原图，不在脸上叠画新的眼睛。旧动态壁纸 ID 已由上游下架，本分支保留兼容文件，但换成原图静帧。

在仓库根执行（Python 需要 `Pillow`、`reportlab`，PATH 中需要 `ffmpeg`）：

```powershell
python scripts/meme-assets/rebuild.py --font C:/Windows/Fonts/msyhbd.ttc
```

生成器保留现有素材尺寸，更新伙伴包头像校验值与壁纸清单，并将所有输出及 SHA-256 写入 `outputs.json`。其他平台可通过 `--font` 指定可用的中文粗体字体；字标排版会随字体变化。

Windows 图标复用仓库的 `generate-win-ico.mjs`（需要已安装 Node 工作区依赖），从同一奶蛋母版生成 16 / 24 / 32 / 48 / 64 / 128 / 256 全部尺寸的 32 位 BMP 条目及透明掩码，同时同步主程序和更新器的 PNG / ICO。安装器在覆盖 EXE 后对程序、已有快捷方式和安装目录发送 Shell 刷新通知，避免 Explorer 在某一图标尺寸继续显示旧缓存。

更新器的 `build.rs` 显式追踪 ICO / PNG 变化，使增量构建重新编译 Windows 图标资源。验证构建时应检查最终 EXE 的全部图标条目，不能只检查输入 ICO 或以 Cargo 编译成功作为资源已更新的依据。

这些 meme 图片是第三方参考素材，不主张原创或通用再分发许可，也不将仓库的软件许可证扩张到这些图片。来源说明见 `SOURCES.json`；原项目的软件版权与许可声明继续保留。

菜单栏、模型来源标记和手机小组件的单色图标采用奶蛋原图的轮廓。手机图标和原生小组件资源属于 runtime fingerprint 输入；这部分需要新的原生安装包，不能仅靠 OTA 更新。此次只构建和安装 Windows Global 版，未发布移动端更新。
